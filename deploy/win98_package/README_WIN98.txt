RetroBrowser for Windows 98
===========================

SYSTEM REQUIREMENTS:
  - Windows 98 Second Edition
  - 64MB RAM minimum, 128MB recommended
  - 200MHz Pentium or faster
  - Winsock 2.2 (included in Win98 SE)

INSTALLATION:
  1. Copy RetroBrowser.exe to C:\RetroBrowser\
  2. Double-click to run
  3. Configure proxy settings if needed

PROXY SETUP:
  - Host: Your host machine IP
  - Port: 8080
  - Run proxy server on host: python src/proxy/proxy.py

TROUBLESHOOTING:
  - If "procedure not found" error: Install Winsock 2.2 update
  - If network fails: Check proxy server is running
  - If crashes: Ensure at least 64MB RAM available

For detailed instructions, see docs\win98_vm_testing_instructions.md
