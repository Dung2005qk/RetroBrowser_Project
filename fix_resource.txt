========================================
FIX RESOURCE FILE CHO VISUAL STUDIO
========================================

Cách 1: Tạo file icon đơn giản
-------------------------------
1. Mở Paint trên Win98
2. Tạo ảnh 32x32 pixels
3. Save as: src\browser\res\app.ico (chọn format 256 colors)
4. Tạo thêm: src\browser\res\hand.cur (cursor 32x32)

Cách 2: Comment out icon trong app.rc
--------------------------------------
Mở file src\browser\res\app.rc, comment 2 dòng:

// IDI_APP_ICON ICON "res\\app.ico"
// IDC_HAND_CURSOR CURSOR "res\\hand.cur"

Cách 3: Sửa đường dẫn tuyệt đối
--------------------------------
Thay:
IDI_APP_ICON ICON "res\\app.ico"

Thành:
IDI_APP_ICON ICON "C:\\RetroBrowser\\src\\browser\\res\\app.ico"
