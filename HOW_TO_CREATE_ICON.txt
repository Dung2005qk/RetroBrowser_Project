========================================
HƯỚNG DẪN TẠO ICON VÀ CURSOR CHO WIN98
========================================

CÁCH 1: Dùng Paint trên Win98 (Đơn giản nhất)
----------------------------------------------
1. Mở Paint (Start → Programs → Accessories → Paint)
2. Image → Attributes → Set size to 32x32 pixels
3. Vẽ một hình đơn giản (ví dụ: hình vuông màu xanh)
4. File → Save As
   - File name: app.bmp
   - Save as type: 256 Color Bitmap (*.bmp)
5. Đổi tên file từ app.bmp thành app.ico
6. Copy vào: F:\src\browser\res\app.ico

Làm tương tự cho cursor:
7. Vẽ hình tay (hoặc bất kỳ hình gì)
8. Save as: hand.bmp
9. Đổi tên thành hand.cur
10. Copy vào: F:\src\browser\res\hand.cur

CÁCH 2: Copy icon từ Windows
-----------------------------
1. Mở Windows Explorer
2. Tìm file C:\Windows\System\shell32.dll
3. Click phải → Properties → Icons (nếu có)
4. Hoặc dùng Resource Hacker (nếu có cài)
5. Extract icon ra file .ico
6. Copy vào F:\src\browser\res\app.ico

CÁCH 3: Dùng icon có sẵn từ Windows
------------------------------------
Copy file icon có sẵn:
copy C:\Windows\notepad.exe F:\src\browser\res\app.ico
copy C:\Windows\System\shell32.dll F:\src\browser\res\hand.cur

(Có thể không work 100% nhưng đủ để build)

CÁCH 4: Tạo file giả tạm thời (Để build được)
----------------------------------------------
Tạo file text rỗng:
echo. > F:\src\browser\res\app.ico
echo. > F:\src\browser\res\hand.cur

Sau đó build sẽ báo lỗi format, nhưng ít nhất file đã tồn tại.
