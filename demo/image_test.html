Test Notes

Current implementation notes:

  • Only BMP format is supported (Win98 native)
  • Images load asynchronously (no UI freeze)
  • Progressive rendering (images appear as they load)
  • Alt text displayed while loading or on error
  • Cache holds up to 50 images with LRU eviction

Creating Test Images

To create test BMP images on Windows:

  1. Open Paint (mspaint.exe)
  2. Create a simple drawing
  3. Save As → BMP format
  4. Host on local web server or proxy

Expected Behavior

When loading this page:

  1. Page appears immediately with text content
  2. Image placeholders show alt text initially
  3. Images load in background (parallel downloads)
  4. Each image appears as soon as decoded
  5. Failed images continue showing alt text
  6. Browser remains responsive during loading

Performance Notes

On a typical Win98 system (200MHz CPU, 56k dialup):

  • Page load: Instant (text only)
  • Per-image load time: 1-5 seconds (depending on size/connection)
  • Total page time: Varies (async, not sequential)
