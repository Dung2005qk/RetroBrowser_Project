Expected Behavior

  • Page loads instantly (text appears immediately)
  • Alt text shows first for all images
  • Images appear progressively (one by one)
  • Browser remains responsive during loading
  • Non-existent image shows alt text permanently

Troubleshooting

If images don't appear:

  1. Check that demo/images/*.bmp files exist
  2. Check proxy is running on port 8888
  3. Check that local HTTP server is running
  4. Check browser console/debug output
